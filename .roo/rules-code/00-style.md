# Code Mode – Style (Bootstrap)
- Enforce formatter: if Python → `ruff format` + `ruff check`; if TS → `biome check --apply` (or `eslint --fix` if Biome unavailable).
- Commits: Conventional Commits; one focused change per commit; include tests/docs when relevant.
- Branching: `feat/*`, `fix/*`, `docs/*`, `chore/*`, `refactor/*`.
- Files you may edit without asking: `src/**`, `app/**`, `packages/**`, `docs/**`, config in root.
