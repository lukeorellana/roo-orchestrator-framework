# /init-architecture

Kick off a new project by running each Architect mode in sequence, then return to the Orchestrator.

1. Switch to **🧭 Product Architect** and answer the Kickoff 12.
   - Writes `docs/PRD.md` and `docs/Assumptions.md`.
2. Switch to **🎨 UX Architect**.
   - Writes `docs/UX-Brief.md` and `docs/Acceptance-Criteria.md`.
3. Switch to **🏗️ Solution Architect**.
   - Writes `docs/ImplementationGuide.md` and `docs/Tech-Choices.md`.
   - Generates stack rules in `.roo/rules-code/`.
4. Finally, switch to **Orchestrator** to plan and delegate the first slice.
